# 🗂️ Reservia 🏨 📍
## Reservia is a responsive page website for an hotels and activities nearby search app. It includes sections like About, Hotels and activities nearby, using HTML and Cs sfor layout and styling.

## ✅ Key Features
- Responsive design (mobile-first)
- Reusable UI (navbar + footer on each page)
- Cards with images for Menu/ Bevarages and Food
- Clean sections for About, Menu, Reservation, Contact, Food, beverages 
- Contact page with a form UI

## 📄Pages Included
- `index.html` (Home)
- `about.html` (About)
- `menu.html` (Menu)
- `beverages.html` (Beverages)
- `food.html` (Food)
- `contact.html` (Contact)
- `reservation.html` (Reservation)

## 🛠️ Tech Stack
- HTML
- CSS
- Bootstrap

##  ▶️ How to Run
Just open the project files in a browser:
1. Download/clone the repository
2. Open `index.html` in your browser
