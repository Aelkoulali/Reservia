# 🗂️ Reservia 🏨 📍
## Reservia is a responsive page website for an hotels and activities nearby search app. It includes sections like About, Hotels and activities nearby, using HTML and Cs sfor layout and styling.

## ✅ Key Features
- Responsive design (mobile-first)
- Reusable UI (navbar + footer)
- Cards with images for hotels  included popular ones
- Search bar with input  
- filters such pets accepted....  

## 🛠️ Tech Stack
- HTML
- CSS


##  ▶️ How to Run
Just open the project files in a browser:
1. Download/clone the repository
2. Open `index.html` in your browser
